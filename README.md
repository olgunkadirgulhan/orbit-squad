# Orbit Squad
Animated space Shorts: the Sun, planets and the Moon as characters sharing real space facts (rounded, based on NASA planetary data).

- `src/` → `./build.sh` → `orbit.py` (engine forked from Countryball Chaos; textures, scenes, music and SFX are generated by code)
- `src/bank.py`: situations and lines (every line is a fact); `tools/gen_voice_lines.py` → `voice_lines.py`
- Voices: `voices/os/<BODY>/<situation>.wav` (Gemini TTS via gecmiste-sen voice-lib `os:<BODY>` jobs, Whisper-checked)
- `run.py`: only fully voiced, never-repeated plans; `videos.yml` gated by repo variable `LAUNCH=on`
